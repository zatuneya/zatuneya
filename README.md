# ざつね屋

中小企業の業務改善と、現場に合わせたシステムの個別実装に取り組んでいます。

日々の作業で手間がかかっていることを整理し、業務ツールの構築、既存業務の効率化、外部サービスとの連携につなげます。AIも活用しながら、使う人や運用に合った仕組みを考えます。

## 対応すること

- 業務の流れや困りごとの整理
- 繰り返し作業を減らす業務ツールの構築
- API（外部サービスとデータをやり取りする仕組み）を使った連携
- ブラウザで使えるWebアプリの開発

## 開発例

自社で企画・開発したツールを紹介します。

### Web制作の業務運営管理｜提供準備中

ヒアリングから見積・請求、制作、公開前の確認、保守まで、Web制作の業務をまとめて管理するデスクトップアプリです。案件ごとの進捗や次にする作業を確認でき、見積書・請求書のPDF作成や、AIを使ったテストサイト案の生成にも対応しています。

使用技術：Electron、JavaScript、Claude API

### 工数・予算管理ツール

工数と単価から予算を計算し、営業日ベースのスケジュールとガントチャートを作成するツールです。遅れが出た場合の再スケジュール提案までを、Googleスプレッドシート上で扱います。

使用技術：Googleスプレッドシート、Google Apps Script

### 人員管理リマインダーBot

チームの状態確認と、管理者への声かけのきっかけづくりを支援するSlack Botです。定期アンケートの送信、回答内容のAI分析、管理者への通知、グループごとのメンバー管理、未回答が続いた場合の通知を実装しています。

使用技術：Python、Slack API、Groq API、SQLite

### 動画自動生成ツール

音声・画像生成を組み合わせ、ショート動画の制作を自動化するデスクトップツールです。

使用技術：Python、Tkinter、MoviePy、VOICEVOX API

### 育児サポートアプリ

生成AIを使った離乳食のレシピ提案と、予防接種のスケジュール管理ができるWebアプリです。

使用技術：HTML、CSS、JavaScript、Gemini API、localStorage

### 漢字書き順アプリ

スマートフォンのブラウザ上で書き順を見て、指でなぞりながら練習する学習用Webアプリです。Canvasによる描画・入力判定、学習記録の保存、Service Workerによるオフライン対応を実装しています。

使用技術：HTML、CSS、JavaScript、Canvas API、Web Audio API、Service Worker
